# agent-skills-en 免费收录渠道 Top 8（2026-10-01 调研）

> 项目：[agent-skills-en](https://github.com/alapha888/agent-skills-en) —— 5 个 MIT 协议的英文 agent skills（文档校对、会议纪要、提交信息、代码审查、深度调研），面向日常知识工作者。
> 筛选标准：免费提交、无手机号/KYC、可邮箱自助注册或免账号表单。以下 URL 均为调研工具返回的真实链接，未编造。**只做调研，不做提交。**
> 已提交的不再列入：SaaSHub（已提交待审）、DevHunt（需 GitHub OAuth，另有安排）、小众软件（中文产品，不相关）。

## 排序逻辑

- **第 1 名 AI Agents Listing**：匹配度唯一"高且专"（skills 是其一级收录对象），提交成本最低（免账号、只交名称+网址），是投入产出比最高的动作。
- **第 2–4 名（Product Hunt / Peerlist / StackShare）**：匹配度高、流量大，但需要注册账号 + 准备素材 +（PH 还需 launch 日运营），成本递增。
- **第 5–8 名**：纯表单、低成本、长尾目录；单个流量小，胜在 10 分钟一个、可批量做。

## 特别说明：skills.sh（不属提交渠道，但值得做）

skills.sh（https://skills.sh）是 agent skills 的事实标准目录（9 万+ skills），但**没有提交入口**——它靠 `npx skills` CLI 的匿名安装遥测自动发现仓库。零成本动作：在仓库 README 里加上 `npx skills add alapha888/agent-skills-en` 安装说明，有人安装即可能被收录。另有 ClawHub（clawhub.com，OpenClaw 生态注册表）属特定 agent 生态，未列入通用 Top 8。
