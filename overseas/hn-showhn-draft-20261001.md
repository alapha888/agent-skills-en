Title: Show HN: 5 free agent skills for everyday knowledge work

Body:

I packaged five small agent skills I use daily into one repo. They work with Claude Code, Codex CLI, and any agent framework that supports skills.

- proofread-pro: proofreads documents with a fixed checklist instead of free-form edits
- meeting-notes: turns raw transcripts into structured notes with decisions and action items
- git-commit-message: writes commit messages in a consistent format your team can scan
- code-review: reviews code for real issues, skips style nitpicks
- deep-research-framework: runs multi-round research with source tracking

Install: `npx skills add alapha888/agent-skills-en`

Each skill is a SKILL.md with instructions plus a couple of worked examples. MIT licensed. Repo: https://github.com/alapha888/agent-skills-en

Happy to hear what's missing or what breaks for you.
